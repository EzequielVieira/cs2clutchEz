# Sample demos

`14155.dem` and `14011.dem` are short CS2 demos from the DemoFile.Net test corpus
(https://github.com/saul/demofile-net/tree/main/demos), distributed under the MIT License
(Copyright (c) 2023 Saul Rennison). They are used only by the automated tests.

Re-download with `tests/download-test-demos.ps1`.

Full-match tests (13+ rounds) use the largest demo found in `CS2HG_TEST_DEMOS` or in the local
CS2 `game/csgo/replays` folder and are skipped when none is available.
